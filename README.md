# DeskPilot 🚀

**The Next-Generation AI Customer Support Platform**

DeskPilot is a production-ready, full-stack B2B SaaS solution designed to revolutionize customer support. Built from the ground up to be scalable and intelligent, it seamlessly blends automated AI assistance with human expertise.

Unlike simple demos, DeskPilot is a robust platform featuring real-time chat, voice capabilities, and a deep-learning knowledge base, all wrapped in a modern, high-performance architecture.

## 🌟 Core Features

-   **🤖 Intelligent Real-Time Chat**: Powered by **Convex Agents**, facilitating dynamic conversations with support for top-tier models like **OpenAI**, **Anthropic**, and **Grok**.
-   **🧠 Advanced Knowledge Base**: Utilizes **Embeddings** and **RAG (Retrieval-Augmented Generation)** to ingest documentation and provide accurate, context-aware answers.
-   **📣 Hybrid Support Flow**: Smartly manages conversations with auto-resolution capabilities and seamless **AI-to-Human Handoff**.
-   **🔊 Voice Capabilities**: Integrated voice support powered by **VAPI** for a complete multi-modal experience.
-   **🛠️ Embeddable Widget**: A lightweight, customizable chat widget that can be dropped into any website.
-   **🏢 Enterprise Management**: Complete support for **Workspaces**, **Team Management**, and **Subscription Billing** via **Clerk**.
-   **🔐 Secure & Scalable**: leveraging **AWS Secrets Manager** for secure key storage and **Sentry** for real-time error tracking.

## 🏗️ Technology Stack

Built with the latest and greatest in web technology:

-   **Framework**: [Next.js 15](https://nextjs.org/)
-   **Core**: [React 19](https://react.dev/)
-   **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
-   **Backend & Realtime**: [Convex](https://convex.dev/)
-   **Monorepo Management**: [Turborepo](https://turbo.build/)
-   **Authentication & Billing**: [Clerk](https://clerk.com/)
-   **Code Quality**: Automated PR reviews by **CodeRabbit**
